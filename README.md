# House Price Prediction using Machine Learning

## Overview
This project predicts house prices using Machine Learning based on features such as area type, location, BHK, total square feet, bathrooms, and balconies.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Model
- Decision Tree Regressor

## Dataset
The dataset contains house details including:
- Area Type
- Availability
- Location
- BHK
- Total Square Feet
- Bathrooms
- Balcony
- Price

## Steps
1. Import the dataset
2. Data preprocessing
3. Feature encoding
4. Train-test split
5. Train Decision Tree model
6. Predict house prices
7. Evaluate the model using MAE, MSE, RMSE, and R² Score

## Result
The model predicts house prices with good accuracy using the Decision Tree Regression algorithm.
